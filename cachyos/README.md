# CachyOS — niri + Noctalia

Config files for my [niri](https://github.com/YaLTeR/niri) + [Noctalia](https://github.com/noctalia-dev/noctalia-shell) desktop on CachyOS.
Setup instructions live in the [root README](../README.md); this file is the file-by-file reference.

## Layout

| Path | Copied from | What it is |
| --- | --- | --- |
| `niri/config.kdl` | `~/.config/niri/config.kdl` | Main niri compositor config |
| `niri/config.kdl.orig` | `~/.config/niri/config.kdl.orig` | Stock niri config, kept for reference |
| `niri/noctalia.kdl` | `~/.config/niri/noctalia.kdl` | Colors niri include, generated by Noctalia's theming |
| `noctalia/settings.toml` | `~/.local/state/noctalia/settings.toml` | Noctalia shell settings (bar, dock, lockscreen, theme, wallpaper) |
| `noctalia/state.toml` | `~/.local/state/noctalia/state.toml` | Noctalia runtime state |
| `nirimod/settings.json` | `~/.config/nirimod/settings.json` | nirimod settings |
| `nirimod/baseline/` | `~/.config/nirimod/baseline/` | nirimod baseline config snapshot |
| `themes/*` | various | Noctalia-generated color themes for other apps |

`themes/` files are all generated by Noctalia's template system from the active
palette, so they will be overwritten whenever the theme changes:

- `gtk-3.0-noctalia.css` → `~/.config/gtk-3.0/noctalia.css`
- `gtk-4.0-noctalia.css` → `~/.config/gtk-4.0/noctalia.css`
- `btop-noctalia.theme` → `~/.config/btop/themes/noctalia.theme`
- `kitty-noctalia.conf` → `~/.config/kitty/themes/noctalia.conf`
- `alacritty-noctalia.toml` → `~/.config/alacritty/themes/noctalia.toml`
- `ghostty-noctalia` → `~/.config/ghostty/themes/noctalia`
- `cava-noctalia` → `~/.config/cava/themes/noctalia`
- `qt5ct-noctalia.conf` → `~/.config/qt5ct/colors/noctalia.conf`
- `qt6ct-noctalia.conf` → `~/.config/qt6ct/colors/noctalia.conf`
- `kde-noctalia.colors` → `~/.local/share/color-schemes/noctalia.colors`

## Deliberately not included

Regenerated automatically or personal to this machine:

- `~/.local/state/noctalia/clipboard/` — clipboard history
- `~/.local/state/noctalia/notification_history.json`
- `~/.local/state/noctalia/usage_counts.json`, `recently_used.json`, `wallpaper_shuffle.json`
- `~/.local/state/noctalia/community-palettes/`, `community-templates/`, `plugins/` — downloaded on demand
- `~/.config/nirimod/backups/` — rolling generation backups
